# 検索パターンの書き方

compromise が文書の一部を選ぶために使う、パターンの言語です。
正規表現に似ていますが、文字ではなく、単語（term）をひとつの単位として扱います。
`.match()`、`.has()`、`.if()`、`.not()`、`.before()`、`.replace()` などのメソッドで使われます。

```js
nlp('猫が寝る').match('#名詞 #格助詞').text()
// '猫が'
```

## 早見表

| パターン       | 意味                                   | 例                    | 見つかるもの                   |
| -------------- | -------------------------------------- | --------------------- | ------------------------------ |
| `単語`         | その単語そのもの                       | `寝る`                | 「寝る」                       |
| `#タグ`        | この[タグ](./tagset.md)を持つ単語      | `#名詞`               | 「猫」                         |
| `.`            | 任意の単語ひとつ                       | `猫 . 寝る`           | 「猫が寝る」                   |
| `*`            | 任意の単語が 0 個以上                  | `猫 * 寝る`           | 「猫がソファで寝る」           |
| `(a\|b)`       | どちらか                               | `(赤\|青)`            | 「赤」または「青」             |
| `(a && b)`     | 両方を満たす単語                       | `(歌 && #名詞)`       | 名詞としての「歌」だけ         |
| `単語?`        | あってもなくてもよい                   | `黒い? 猫`            | 「猫」と「黒い猫」             |
| `単語+`        | 1 個以上                               | `#形容詞+`            | 「小さい黒い」                 |
| `単語{m,n}`    | m 個から n 個                          | `.{2,3}`              | 2 個か 3 個の単語              |
| `!単語`        | これ以外のもの                         | `猫 !#動詞`           | 「猫が」                       |
| `^`            | 文の先頭                               | `^猫`                 | 文頭の「猫」                   |
| `$`            | 文の末尾                               | `寝る$`               | 文末の「寝る」                 |
| `[単語]`       | キャプチャグループ                     | `[.] の 値段`         | 「牛乳」                       |
| `[<名前>単語]` | 名前付きキャプチャグループ             | `[<もの>.] の 値段`   | `もの` という名前で「牛乳」    |
| `{辞書形}`     | この単語のすべての活用形               | `{売る}`              | 「売る」「売りました」         |
| `~単語~`       | あいまい検索（近いつづりを見つける）   | `~コンピューター~`    | 「コンピュータ」               |
| `/regex/`      | 単語ひとつに対して試される正規表現     | `/^[猫犬]$/`          | 「猫」「犬」                   |
| `@メソッド`    | 単語に対するテスト                     | `@isUpperCase`        | 「NASA」                       |

これらは組み合わせることができます。`#名詞+?` はあってもなくてもよい名詞の連続で、`^[<最初>.]` は最初の単語を取り出します。

## 単語

日本語は単語のあいだにスペースを入れませんが、パターンの中では、単語をひとつずつスペースで区切ります。
どこで区切られるかは `.terms()` で確かめられます。

```js
nlp('猫が寝る').terms().out('array') // ['猫', 'が', '寝る']
nlp('猫が寝る').match('猫 が').text() // '猫が'
nlp('猫が寝る').has('猫が') // false
```

ふつうの単語は、その単語そのものだけを見つけます。同じ単語のほかの活用形は見つけません:

```js
nlp('私は本を読んだ').has('読んだ') // true
nlp('私は本を読んだ').has('読む') // false
```

すべての活用形を見つけるには `{読む}` を使います。下の[辞書形](#辞書形)を見てください。

## タグ

`#タグ` は、そのタグを持つすべての単語を見つけます。使えるタグは[タグ一覧](./tagset.md)にあります。

タグは階層になっています。`#名` は `#人名` でもあり、`#名詞` でもあります。

```js
nlp('猫が寝る').match('#名詞').text() // '猫'
```

存在しないタグは何も見つけず、エラーも出しません:

```js
nlp('猫が寝る').match('#Nouns').found // false
```

タグの名前は、英語でも日本語でも同じように使えます。`#RB` のような Penn 形式の名前も使えます。

```js
nlp('猫が寝る').match('#名詞 #格助詞').text() // '猫が'
nlp('猫が寝る').match('#Noun #CaseParticle').text() // '猫が'
```

## ワイルドカード

`.` はちょうどひとつの単語です。`*` は 0 個を含む任意の数の単語で、できるだけ多く取ります。

```js
nlp('猫が寝る').match('猫 . 寝る').text() // '猫が寝る'
nlp('黒い猫がソファで寝る').match('猫 * 寝る').text() // '猫がソファで寝る'
```

## 選択肢

`(a|b)` は選択肢のどれかひとつを見つけます。`(a && b)` は単語がすべてを満たすことを求めるので、ふたつの品詞になりうる単語に便利です。

```js
nlp('赤と青が好き').match('(赤|青)').out('array') // ['赤', '青']
nlp('歌を歌う').match('(歌 && #名詞)').out('array') // ['歌']
```

グループは入れ子にできません。`(大きい (赤い|青い))` は使えないので、`.match()` を 2 回呼んでください。

## 省略できる単語と繰り返し

```js
nlp('猫').match('黒い? 猫').text() // '猫'
nlp('黒い猫').match('黒い? 猫').text() // '黒い猫'

nlp('小さい黒い猫が寝る').match('#形容詞+').text() // '小さい黒い'
nlp('黒い猫がソファで寝る').match('.{2,3}').out('array') // ['黒い猫が', 'ソファで寝る']
```

`{n}` はちょうど n 個、`{m,n}` は m 個から n 個、`{m,}` は m 個以上、`{,n}` は n 個までです。

## 否定

```js
nlp('猫が寝る').match('猫 !#動詞').text() // '猫が'
```

## 先頭と末尾

`^` と `$` は、文書ではなく、文の先頭と末尾です。

```js
nlp('猫が寝る').match('^猫').text() // '猫'
nlp('猫が寝る').match('寝る$').text() // '寝る'
```

## キャプチャグループ

角かっこは、見つかったもののうち、取っておきたい部分を示します。`.groups()` で取り出すか、グループを 2 番目の引数として渡します:

```js
const doc = nlp('牛乳の値段は高い')
doc.match('[<もの>.] の 値段').groups('もの').text() // '牛乳'
doc.match('[.] の 値段', 0).text() // '牛乳'
```

名前がないとき、グループには 0 から番号が付きます。ひとつのグループに複数の単語を入れることもできます。

## 辞書形

`{辞書形}` は、辞書に載っている形をもとに、その単語のすべての活用形を見つけます。

辞書形は最初から計算されているわけではありません。先に `doc.compute('root')` を実行してください。

```js
const doc = nlp('彼女は貝殻を売りました。')
doc.compute('root')
doc.match('{売る}').text() // '売りました。'
```

## あいまい検索

`~単語~` は、文字列の距離をもとに、近いつづりを見つけます。しきい値は標準で 0.85 で、[オプション](#検索オプション)で変えられます。

```js
nlp('コンピュータを使う').match('~コンピューター~').text() // 'コンピュータ'
```

## 正規表現

`/regex/` は単語ひとつずつに対して試されるので、ふたつの単語にまたがることはできません。

```js
nlp('猫と犬がいる').match('/^[猫犬]$/').out('array') // ['猫', '犬']
```

## 単語に対するテスト

`@メソッド` は、組み込みのテストをそれぞれの単語に適用します。よく使うものは `@isTitleCase`、`@isUpperCase`、`@hasComma`、`@hasHyphen`、`@hasContraction`、`@hasQuote` です。大文字・小文字のテストは、ラテン文字で書かれた単語にだけ意味があります。

```js
nlp('TokyoとNASA').match('@isUpperCase').out('array') // ['NASA']
```

## 検索オプション

`.match()`、`.matchOne()`、`.has()`、`.if()`、`.ifNo()`、`.before()`、`.after()` は、キャプチャグループの次の 3 番目の引数として、オプションのオブジェクトを受け取ります。

| オプション      | 標準    | 効果                                                       |
| --------------- | ------- | ---------------------------------------------------------- |
| `fuzzy`         | `0.85`  | `~単語~` が一致するのに必要な類似度（0 から 1）            |
| `caseSensitive` | `false` | 整えられた形ではなく、もとのテキストと比べる               |
| `noRegex`       | `false` | `/regex/` をふつうの単語として扱い、決して実行しない       |

```js
nlp('NASAとnasa').match('NASA', null, { caseSensitive: true }).out('array') // ['NASA']
```

パターンをユーザーが書いた場合は `{ noRegex: true }` を使ってください。遅い正規表現や壊れた正規表現が実行されるのを防げます。

## 単語のリストを探す

ふつうの単語の長いリストを探すなら、`.match()` を何度も呼ぶより `.lookup()` のほうがずっと速くなります。検索パターンの書き方を使わないので、ユーザーが入力した単語にも安全です。

```js
nlp('太郎と花子を見た').lookup(['太郎', '花子']).out('array') // ['太郎', '花子']
```

## パターンを使い回す

`nlp.parseMatch(str)` はパターンを一度だけ解析し、何度でも使えるようにします。`nlp.buildNet([...])` は多くのパターンをひとつにまとめ、`.sweep()` で一度に実行できるようにします。同じパターンを大量のテキストに使うときに役立ちます。

## できないこと

- **入れ子のグループ。** `.match()` を複数回呼んでください。
- **文をまたぐパターン。** 見つかるものは、どれもひとつの文の中に収まります。
- **複数の単語にまたがる正規表現。** `/regex/` は単語ひとつずつに対して試されます。

## 何も見つからないとき

1. タグが[タグ一覧](./tagset.md)にあるか確かめる。
2. `doc.debug()` で、それぞれの単語に付いたタグを見る。
3. パターンの中の単語がスペースで区切られているか確かめる。区切り方は `.terms()` でわかります。
4. ふつうの単語は完全一致であることを思い出す。すべての活用形には `{辞書形}` を使います。
5. パターンは文をまたがないことを思い出す。
