# 貢献するには

このライブラリは開発の途中にあり、開発者と日本語話者の両方の助けを必要としています。

プログラマーでなくても協力できます。タグが間違っている単語を [issue](https://github.com/nlp-compromise/ja-compromise/issues) で知らせてもらえるだけでも、役に立つ貢献です。日本語でも英語でもかまいません。

プルリクエストはどれも歓迎で、できるだけ早く確認します。このライブラリはオープンソースで、MIT ライセンスです。

### セットアップ

GitHub でリポジトリを自分のアカウントにフォークしてから:

```bash
git clone git@github.com:{あなたのユーザー名}/ja-compromise.git
cd ja-compromise
pnpm install
pnpm test
```

このプロジェクトは [pnpm](https://pnpm.io/) を使っています。`npm install` と `npm test` でも動きます。

### 変更する

- `./src` にコードがあります。`01-one`（分かち書き、活用、数、ローマ字）と `02-two`（タグ付け）に分かれています。
- `./lexicon` に単語リストがあります。これらは圧縮して使われるので、変更したあとは `pnpm run pack` を実行して結果を確かめてください。
- `./tests` にテストがあります。変更にはテストを追加してください。
- `./scratch.js` は試し書き用のファイルです。`pnpm run watch` を使うと、保存するたびに実行し直されます。
- `pnpm run score` は、分かち書きとタグ付けを `./learn/test/gold.js` と照らし合わせて確かめます。

文にどのようなタグが付いたかを見るには、`.debug()` を使います:

```js
nlp('彼女は浜辺で貝殻を売る。').debug()
```

### プルリクエストを送る

`dev` ブランチをもとに作業し、プルリクエストも `dev` ブランチに送ってください。

大きな変更の場合は、先に issue を作って相談してください。
